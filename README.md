# OTT Content Analytics Dashboard | Power BI

## Project Overview
This project presents an OTT Content Analytics dashboard developed using Microsoft Power BI. It focuses on exploring and visualizing streaming-platform content data to make the information easier to understand through interactive reports and visualizations.

## Objectives
- Analyze OTT content data.
- Explore content distribution and patterns.
- Present key insights through data visualizations.
- Build an interactive dashboard for data exploration.
